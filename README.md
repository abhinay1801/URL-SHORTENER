## Overview
The **URL Shortener Platform** is a web application built using the **MERN stack**.  
It allows users to create **short, shareable links** from long URLs, generate **QR codes**, and view **detailed analytics** such as clicks, devices, and locations.  

This project makes link sharing **faster, easier, and trackable** for both individuals and businesses.  

---

## Features
- Shorten long URLs into simple links.  
- Create **custom aliases** and set expiry time.  
- Track **click analytics** (count, location, device, referrer).  
- View **click history** with date and time.  
- Generate a **QR code** for every shortened link.  
- Fast redirection with tracking.  
- Validation to ensure only valid URLs are accepted.  

---

## Tech Stack

- **Frontend** → React.js, Tailwind CSS  
- **Backend** → Node.js, Express.js  
- **Database** → MongoDB 
- **Other Tools** → Chart.js (analytics charts), QRCode (QR generator)
